# Issue Tracker

## Platform

GitHub Issues.

## Conventions

- Issues are the canonical source of work items for this repo.
- Use `gh` CLI for all issue operations.
- One issue per feature, bug, or discrete task.
- Labels, milestones, and assignments follow GitHub conventions.

## Workflow

- Create issues with `gh issue create`.
- Reference issues from commits and PRs using `#<number>`.
- Close issues via PR merge or manual close.
